# brim 界面用语

界面上的字（中文和英文）都按这张表。设计稿、README、聊天里可以随口叫，但**界面里不用戏称**。2026-10-29 shiqi 定。

| 指的是什么 | 中文 | English | 界面里不用 |
| --- | --- | --- | --- |
| 屏幕顶部放摄像头的那一块（硬件） | 摄像头区域 | camera area | 刘海、刘海屏 |
| brim 在摄像头区域旁边画的、鼠标停上去会展开的黑色面板 | 顶部面板 | top panel | 刘海 |
| 顶部面板旁边那棵像素松 | 松树 | pine | 松（单字） |
| 松树出现时一行一行长出来的动画 | 生长动画 | growth animation | 再长一次 |
| 菜单栏收纳这个功能 | 收纳 | Stash | |
| 用户自己建的、菜单栏上露出来的那个小图标 | 收纳格 | box | 格子 |
| 收纳格的外观（帽檐、松树、石灯笼……） | 样式 | style | 样子 |
| 不在菜单栏上显示 | 隐藏 / 已隐藏 | hide / hidden | 藏、藏着 |
| 在菜单栏上显示 | 显示在菜单栏 | show in menu bar | 露在外面 |
| 正在执行任务的 agent | 运行中 | working | 在干活 |
| 没在执行任务 | 空闲 | idle | 歇着 |
| 官方的用量上限还剩多少 | 剩余额度 | remaining | |
| 开始查某家的额度 | 开启 | Turn on | 接上 |
| 拒绝 / 以后再说 | 不开启 / 以后再说 | Not now | 不用、先不用 |
| 把 brim 拷进“应用程序”文件夹 | 移到“应用程序” | Move to Applications | 挪过去 |
| 删除收纳格 | 删除 | Delete | 删掉 |
| 打开这类 app 时的动画：变成胶囊升到菜单栏 | 岛 | Island | 灵动岛 |
| 打开这类 app 时的动画：图标飞回原位 | 归位 | Return | |

写法：

- 界面里提到系统的名字（“应用程序”“辅助功能”“系统设置”）用中文引号 “”，和 macOS 中文版一致，不用「」。
- agent 照写英文，中文界面里也一样；品牌和产品名照硬规则全小写（brim、sniai yard）。
- 语气平实，说清楚“是什么、要做什么”，不卖萌、不用口语缩略。设计稿和 README 可以保留原来的叫法。
- 中英文切换：设置 › 通用 › 语言（跟随系统 / 中文 / English），马上生效。系统语言是中文时默认中文，其余默认英文。
